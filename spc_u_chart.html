calc_u(data, area) 核心算法与失控分析看板

统计过程控制 (SPC) · 基于 _calc_u_limits 动态限值 (可变样本面积)

数据集: USPC p276 (NofLeaks / NofRadiators)
样本容量 n = 变化 (32~58) | 全局 ū = 0.1379

1 核心算法计算流水线 (处理可变面积 Variable Area)

阶段一：单位缺陷计算与总均值 (u_bar)
1. 各子组单位缺陷数 (u_i)
u_1 = 14 / 39 = 0.3590
u_2 = 4 / 45 = 0.0889
u_i = defect_counts[i] / area_list[i]
2. 总体中心线 (Center Line - u_bar)
u_bar = ∑defects / ∑area = 116 / 841 = 0.1379
传入 _calc_u_limits 的基准
阶段二：单点限值计算 (针对可变面积 n_i) 特点: 限值为阶梯状 (Staircase)
局部标准误差 (随面积变化):
limit_i = math.sqrt(u_bar / area_i)
示例点 1 (n=39): limit = √(0.1379 / 39) = 0.0594 → UCL = 0.3163
示例点 11 (n=32): limit = √(0.1379 / 32) = 0.0657 → UCL = 0.3349
