calc_p(data, sample_size) 核心算法与失控分析看板

统计过程控制 (SPC) · 基于 _calc_p_limits 内部单点限值推导机制

缺陷数: [3, 2, 15, 1, 5, 2, 18, 2, 1, 4]
样本容量: n = 100 | 全局 p̄ = 0.0530

1 核心算法计算流水线 (阶段二对接 _calc_p_limits 逻辑)

输入: defect_counts = [3, 2, 15, 1, 5, 2, 18, 2, 1, 4], sample_sizes = [100 × 10]
阶段一：比率折算与加权中心线计算 (保持原逻辑)
1. 各子组不合格率 (value / p_i)
p = [0.03, 0.02, 0.15, 0.01, 0.05, 0.02, 0.18, 0.02, 0.01, 0.04]
p_i = defect_counts[i] / sample_sizes[i]
2. 中心线 (Center Line - p_bar)
p_bar = ∑defects / ∑n = 53 / 1000 = 0.0530
作为传入 _calc_p_limits 的 proportion 基准
阶段二：_calc_p_limits 动态限值与截断计算 入参: proportion = 0.0530, sample_size = 100
局部标准误差步长 (limit 计算):
limit = math.sqrt(proportion * (1 - proportion) / sample_size) = 0.02240
※ 边界保护: 若 sample_size ≤ 0，直接返回 0 限值熔断字典
上界组 (限制最大为 1.0):
uclx = min(p + 3*limit, 1.0) = 0.1202
usigma2x = min(p + 2*limit, 1.0) = 0.0978
usigma1x = min(p + 1*limit, 1.0) = 0.0754
下界组 (限制最小为 0.0):
lsigma1x = max(p - 1*limit, 0.0) = 0.0306
lsigma2x = max(p - 2*limit, 0.0) = 0.0082
lclx = max(p - 3*limit, 0.0) = 0.0000
字典占位标识: 'var_ucl': 0, 'var_cl': 0, 'var_lcl': 0 (P 图无单独极差变异子图)
阶段三：组装 df_result ➔ 传递给 plot_control_chart(ChartType.P) 生成 Plotly 视图

2 P 控制图实时交互渲染 (完整六区警戒线 + 异常高亮)

展示 _calc_p_limits 输出的参考限，第 3 点与第 7 点越界触发 Rule 1 失控报警

单子图模式 · 支持缩放与悬停探查
