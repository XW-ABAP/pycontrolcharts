calc_np(data, sample_size) 核心算法与失控分析看板

统计过程控制 (SPC) · 基于 _calc_np_limits 内部单点计数限值推导机制

缺陷数: [3, 2, 15, 1, 5, 2, 18, 2, 1, 4]
样本容量: n = 100 | 平均不合格率 p̄ = 0.0530 | 中心线 np̄ = 5.3000

1 核心算法计算流水线 (阶段二对接 _calc_np_limits 逻辑)

输入: defect_counts = [3, 2, 15, 1, 5, 2, 18, 2, 1, 4], sample_size = 100
阶段一：平均不合格率与加权中心线计算 (保持原逻辑)
1. 平均不合格率 (p_bar)
p_bar = ∑defects / (k * n) = 53 / 1000 = 0.0530
各子组不合格数: [3, 2, 15, 1, 5, 2, 18, 2, 1, 4]
2. 计件中心线 (np_bar)
np_bar = p_bar * sample_size = 5.3000
作为传入 _calc_np_limits 的计数基准
阶段二：_calc_np_limits 动态限值与截断计算 入参: p_bar = 0.0530, sample_size = 100
二项分布标准误差步长 (limit 计算):
limit = math.sqrt(np_bar * (1 - p_bar)) = math.sqrt(5.30 * 0.947) = 2.2403
※ 计数不合格品数直接基于频数统计，上界无 1.0 封顶限制（可大于样本量或由 3σ 决定）
上界组 (+3σ 控制上限):
uclx = np_bar + 3 * limit = 12.0209
usigma2x = np_bar + 2 * limit = 9.7806
usigma1x = np_bar + 1 * limit = 7.5403
下界组 (-3σ 截断为 0.0):
lsigma1x = max(np_bar - 1 * limit, 0.0) = 3.0597
lsigma2x = max(np_bar - 2 * limit, 0.0) = 0.8194
lclx = max(np_bar - 3 * limit, 0.0) = 0.0000
字典占位标识: 'var_ucl': 0, 'var_cl': 0, 'var_lcl': 0 (NP 控制图无单独极差变异子图)
阶段三：组装 df_result ➔ 传递给 plot_control_chart(ChartType.NP) 生成 Plotly 视图

2 NP 控制图实时交互渲染 (完整六区警戒线 + 异常高亮)

展示 _calc_np_limits 输出的参考限，第 3 点 (15) 与第 7 点 (18) 超过 UCL (12.0209) 触发 Rule 1 失控报警
